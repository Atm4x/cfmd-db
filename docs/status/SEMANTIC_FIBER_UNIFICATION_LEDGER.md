One atomic equality authority per revision/store snapshot:
`Value -> pinned equivalence -> canonical semantic class -> physical EqClassId`.
SAMF support atoms are local routing over tuples of those atomic IDs, not a second semantic class system.

- SAMF-local observable definitions, product-class interning and product projection authority are removed from production state.
- Canonical reconstruction goes through the shared catalog; durable ObservableAtom tuples remain canonical values, not physical IDs.
- Insert/remove ordering preserves catalog liveness through the entire candidate-snapshot mutation.
