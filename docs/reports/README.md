# Reports

- `current/` — the current closeout/release-preparation reports that describe the checked-in repository state;
- `archive/pass-NNN/` — immutable historical pass reports, diffs, gate logs, freeze records and source snapshots.

Current repository baseline:

- [`current/PASS280_REPORT.md`](current/PASS280_REPORT.md) — global kernel hostile/refactor closeout;
- [`current/RELEASE_PREP_2026-09-28.md`](current/RELEASE_PREP_2026-09-28.md) — documentation/CI/GitHub synchronization and product-roadmap preparation.

When a current report is superseded, move it into its numbered archive folder rather than leaving pass files in the repository root.
